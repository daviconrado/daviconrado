# Opa, meu nome é Davi Conrado 👋

### Sobre mim

Sou estudante de **Engenharia de Software na UTFPR** e atualmente atuo como **Analista de DevOps na CISS**.

Minha trajetória começou no desenvolvimento de software, principalmente com **Nest.js, TypeScript, Next.js e Java**, e evoluiu para uma atuação mais próxima de **DevOps, Platform Engineering e Developer Experience**.

Hoje trabalho principalmente com **CI/CD, automação de processos, governança de desenvolvimento e plataformas internas**, buscando tornar os fluxos de entrega mais padronizados, rastreáveis, seguros e eficientes.

Também sou certificado **AWS Certified Cloud Practitioner** e venho aprofundando meus conhecimentos em **Kubernetes, containers, infraestrutura, segurança e Cloud Native**.
